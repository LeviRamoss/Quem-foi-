# Base de conhecimento do Quem Foi?

24 documentos usados pelo RAG para gerar casos coerentes.

- **Origem:** todos foram escritos pelo grupo Mentalistas para o projeto.
- **Fictícios:** personagens, lugares, objetos e acontecimentos são inventados. Nenhum dado pessoal real foi usado.
- **Conteúdo:** 8 personagens, 6 locais, 6 armas e 4 guias.
- **Índice:** `indice.csv` lista cada documento com tipo, arquivo e origem.
