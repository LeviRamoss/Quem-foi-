# Cozinha

**Descrição:** Bancada de mármore, cepo de facas, despensa e porta dos fundos para o jardim.

**Acessos:** Porta para a sala de estar e porta dos fundos para o jardim.

**Vestígios possíveis:** Faca fora do cepo, louça lavada fora de hora, pegadas no piso molhado.
